# Microburbs

> Microburbs publishes street-level property and suburb data for Australia:
> growth analysis, livability and risk scores, demographics, school and
> transport access, and comparable sales — built from 25 years of sales
> history and ABS data, aggregated to suburb (ABS SAL) and mesh-block
> ("microburb") level.

Reports are web pages that re-generate as new data lands, not static PDFs.
Some report content is behind a paid plan; the previews, research and
reference pages linked below are open.

## Products

- [Suburb reports](https://www.microburbs.com.au/suburb-reports): per-suburb analysis — growth,
  demographics, lifestyle, risk, real estate.
- [Property reports](https://www.microburbs.com.au/property-reports): per-address valuation
  context, comparables and neighbourhood detail.
- [Suburb Finder](https://www.microburbs.com.au/suburb-finder): screen every Australian suburb
  on 20+ variables across real estate, amenity, risk and gentrification.
- [Property Finder](https://www.microburbs.com.au/property-finder): filter listings on the same
  underlying data.

## For developers and agents

- [API access](https://www.microburbs.com.au/api-access): what the public API covers and how it
  is priced.
- [API documentation](https://www.microburbs.com.au/developers/api-docs): interactive reference.
- [OpenAPI specification](https://www.microburbs.com.au/openapi.json): machine-readable spec for
  the public API.
- [MCP server](https://www.microburbs.com.au/developers/mcp): the same data as MCP tools, at
  https://mcp.microburbs.com.au/sse (SSE transport, not /mcp).
- The API is metered and requires a bearer token. There is no unauthenticated
  route to paid report data — please do not attempt to reach it by scraping
  report pages.
